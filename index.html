Demander un devis

Audit de code statique, en lecture seule. Je ne modifie rien, je ne publie rien de votre code, je vous rends un rapport avec les motifs à vérifier, chacun référencé fichier:ligne.

Ce que vous obtenez

Rapport honnête : un constat est un motif à vérifier, pas une vulnérabilité confirmée. Empreinte SHA-256 recalculable. Format visible ici : rapport-exemple.html.

Demander

Le bouton ouvre une nouvelle Issue GitHub déjà étiquetée demande-devis : c'est la voie réellement disponible depuis ce site statique. Rien n'est envoyé tant que vous n'avez pas validé le formulaire dans votre navigateur.

Ouvrir ma demande de devis
Limites. Tarif : fourchette indicative au devis, montant et devise convenus avant commande. Paiement : PayPal ou virement professionnel uniquement — aucune cryptomonnaie. Preuve de réception réelle exigée avant livraison finale.

Ce que je ne fais pas

  • Je n'exécute pas votre code.
  • Je n'accède pas à vos serveurs.
  • Je ne publie pas votre code ni vos identifiants.
  • Je ne vous démarché pas ailleurs : je réponds à votre demande, pas l'inverse.
