Audit de motifs

Un auditeur statique en un seul fichier. Vous le lancez sur votre code, vous obtenez un rapport fichier:ligne reproductible. Aucune installation, aucun compte, aucune donnée envoyée nulle part.

Ce que ce n'est pas

Un motif détecté n'est pas une vulnérabilité confirmée. Ce balayage n'est pas exhaustif. Nous refusons de prétendre l'inverse — c'est écrit dans chaque rapport.

Ce que ça détecte

  • Secrets en dur (mot de passe, clé API, token)
  • Exécution de commande / shell, eval, code dynamique
  • Insertion HTML (risque XSS), CORS ouvert à toutes les origines
  • Concaténation SQL possible, URL http en clair

Chaque constat indique sa catégorie : production, test ou doc.

Fonctionne — preuve réelle

Exécuté sur du code réel : 55 motifs (29 haute, 19 moyenne, 7 basse).

Vous recalculez ce hash vous-même (certutil -hashfile rapport.md SHA256 ou sha256sum). Aucune confiance envers l'auteur n'est requise.

Utilisation

Trois façons de l'utiliser

1. Le fichier, gratuit — disponible sur demande via une issue GitHub. Le fichier s'exécute, vous le gardez.
2. La GitHub Action — ajoutez-la à votre dépôt, un rapport à chaque commit.
3. L'audit personnalisé, sur devis — revue manuelle du contexte et hiérarchisation réelle des constats. Montant et devise convenus avant la commande. Aucun prélèvement automatique. Paiement PayPal ou virement après accord.
