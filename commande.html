Commander un audit de code statique

Je lis votre source et je rends un rapport court, daté, scellé. Aucun code exécuté chez vous. Aucun accès demandé.

Ce que vous recevez

  • Un rapport daté, avec fichier + ligne pour chaque point.
  • Le contexte de chaque ligne, pour écarter les faux positifs évidents.
  • Une empreinte SHA-256 : le rapport est vérifiable, il ne peut pas être modifié après coup.
  • Une distinction claire : point à vérifier vs motif écarté (légitime).
