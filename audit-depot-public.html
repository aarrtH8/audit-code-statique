Audit de code statique d'un dépôt public

Collez l'URL d'un dépôt GitHub public. Vous recevez immédiatement un rapport : secrets en clair éventuels, motifs à examiner, empreinte de ce qui a été analysé, et ce que la méthode ne prouve pas.

Aucun compte. Aucun dépôt privé. Aucun code exécuté. Quelques analyses par heure maximum.

Ce que c'est : une analyse automatique de motifs sur les fichiers texte du dépôt.

Ce que ce n'est pas : une revue humaine, ni une garantie d'absence de faille. Un secret retiré du dernier commit mais resté dans l'historique n'apparaît pas. Un motif signalé peut être légitime.

Aller plus loin : une relecture humaine, avec correctifs priorisés et ordre d'application, se chiffre sur devis après accord — jamais avant.
