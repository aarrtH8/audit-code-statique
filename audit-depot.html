Audit de dépôt en libre-service

Entrez un dépôt GitHub public (auteur/dépôt). L'audit s'exécute dans votre navigateur : les fichiers sont lus depuis raw.githubusercontent.com, rien n'est envoyé à un serveur tiers, rien n'est stocké.

Analyse statique par motifs. Vous obtenez des alertes à vérifier citées fichier + ligne — pas des vulnérabilités confirmées. Aucun code n'est exécuté.

Limites, écrites noir sur blanc

  • Dépôt public uniquement. Aucun accès à un dépôt privé sans votre accord explicite.
  • L'API GitHub non authentifiée est limitée (~60 requêtes/h par IP) : sur un gros dépôt, l'audit peut s'arrêter à mi-chemin — c'est affiché, pas caché.
  • Analyse par motifs : aucun impact réel n'est confirmé. Un constat peut être légitime (test, exemple, code mort).
  • Ce n'est ni un test d'intrusion, ni une revue manuelle ligne à ligne.
