Six cas que je cherche dans du code réel

Chaque page explique un problème courant, montre le code fautif et sa correction, puis indique comment le repérer automatiquement. Ce sont des explications générales — pas le résultat d'un audit sur votre code.

  • Secrets en dur dans le code : comment les repérer
    Clé API, mot de passe ou jeton écrit en clair dans un fichier source : pourquoi c'est un problème et comment le trouver dans un dépôt.
  • Injection SQL par concaténation : le cas le plus courant
    Comment une requête SQL construite par concaténation de chaînes devient injectable, et pourquoi les requêtes préparées ne couvrent pas tous les cas.
  • Pourquoi MD5 et SHA-1 sont inadaptés aux mots de passe
    MD5 et SHA-1 sont rapides : c'est exactement ce qui les rend mauvais pour hacher un mot de passe. Ce qu'il faut utiliser à la place.
  • CORS ouvert et CSRF désactivé : deux réglages qui s'annulent
    Un CORS en étoile et un CSRF désactivé se combinent pour ouvrir une application à des requêtes non désirées. Comment le repérer.
  • Erreurs avalées : le bug qui ne laisse pas de trace
    Un catch vide transforme une panne visible en échec silencieux. Pourquoi c'est risqué et comment le repérer dans un dépôt.
  • Dates et fuseaux : les décalages qui ne plantent jamais
    Une date en heure locale, un mois entre 0 et 11, un passage à l'heure d'été : ces erreurs se propagent sans lever d'exception.
