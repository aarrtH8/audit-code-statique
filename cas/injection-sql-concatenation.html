Injection SQL par concaténation : le cas le plus courant

L'injection SQL n'est pas exotique : elle apparaît dès qu'une valeur d'entrée est concaténée dans une requête. Les requêtes préparées la bloquent quasi toujours — sauf là où l'entrée est injectée dans un nom de table ou une clause ORDER BY.

Ce qui doit alerter

db.query("SELECT * FROM users WHERE email = '" + email + "'");
db.query("SELECT * FROM " + table + " ORDER BY " + col);

Ce qu'on écrit à la place

db.query("SELECT * FROM users WHERE email = ?", [email]);
// ORDER BY et noms de tables : liste blanche stricte, jamais l'entree brute.
