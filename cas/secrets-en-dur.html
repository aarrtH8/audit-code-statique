Secrets en dur dans le code : comment les repérer

Une clé écrite en clair dans le code survit à tous vos nettoyages : elle reste dans l'historique Git, dans les forks, dans les archives de CI. La bonne question n'est pas « est-ce que je l'ai nettoyée ? » mais « est-ce qu'elle est encore dans mon historique ? ».

Ce qui doit alerter

const client = new Stripe("sk_live_51H8x...");
const db = mysql.createConnection({ password: "P@ssw0rd2024" });

Ce qu'on écrit à la place

const client = new Stripe(process.env.STRIPE_SECRET_KEY);
// Jamais de valeur reelle dans le depot ; .env est ignore par Git.

Comment le repérer dans un dépôt réel

Chercher les affectations dont la valeur ressemble à un secret : préfixes connus, longueur anormale, entropie élevée. Un audit statique fait exactement cela : il parcourt vos fichiers et rend une liste de pistes à vérifier, chacune avec fichier:ligne, pour que vous jugiez en une minute si le constat tient.
