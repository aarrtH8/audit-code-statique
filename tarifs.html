Tarifs et périmètre

Audit de code statique pour PME, indépendants et équipes techniques. Prix sur devis, convenus avant le début du travail. Aucun frais caché, aucune sous-traitance opaque.

Comment ça marche : je lis votre code (dépôt privé, archive zip ou extrait ciblé), je produis un rapport fichier + ligne, je distingue motifs détectés et vulnérabilités confirmées, puis je vous propose un plan de correction priorisé. Je n'exécute pas votre code et je n'y accède qu'avec votre accord écrit ; suppression garantie après livraison.

Prestations

1. Audit ciblé — à partir de 90 €

Périmètre : un module, un dépôt, ou un fichier « point chaud » que vous désignez. Idéal pour vérifier un avant-déploiement.

  • Analyse statique complète du périmètre choisi (règles : secrets, injection, exécution dynamique, accès, transport, CORS).
  • Rapport fichier + ligne, classé par gravité, avec faux positifs signalés et écartés.
  • Plan de correction priorisé (quick wins d'abord).
  • Délai indicatif : 2 à 5 jours ouvrés selon le volume.

2. Audit complet de projet — à partir de 290 €

Périmètre : l'ensemble de votre application web, backend et frontend.

  • Tout ce qui précède, sur l'ensemble du code source.
  • Cartographie des zones à risque, avec emplacements précis.
  • Vérification des dépendances : versions obsolètes à risque connu.
  • Appel de restitution de 45 min (visio ou écrit) pour parcourir les résultats.
  • Délai indicatif : 5 à 10 jours ouvrés.

3. Audit de conformité & historique — à partir de 490 €

Périmètre : dépôt à long historique, exigence de preuve documentée.

  • Analyse incluant l'historique Git (secrets déjà commités, même retirés).
  • Rapport structuré pour un auditeur externe ou un client final.
  • Liste de remédiation datée et reproductible.
  • Délai convenu au devis.

Estimer en une commande (public)

Pour un dépôt public, l'estimation se fait sans rien installer d'autre que Node :

node tools/estimer.mjs https://github.com/votre-orga/votre-repo

Sortie : nombre de fichiers et de lignes de code, langages, palier et prix de départ. Prix ferme ensuite au devis. Pour un dépôt privé, envoyer une archive zip ou un accès en lecture — aucun code n'est exécuté.
