Audit de code statique dans votre intégration continue — gratuit

Ajoutez un fichier, vos pushes sont analysés automatiquement. Le rapport sort en artefact. Aucun code n'est exécuté.

Pourquoi c'est gratuit : c'est un outil sérieux, pas une démonstration. Si l'analyse automatique vous signale quelque chose de délicat et que vous voulez un audit humain commenté, avec faux positifs écartés et plan de correction, c'est là que je facture. Vous ne payez rien pour l'outil.

Installation en 3 étapes

1
Créez le fichier .github/workflows/audit-code.yml dans votre dépôt.
2
Collez son contenu (téléchargeable ci-dessous).
3
Poussez. Le rapport apparaît dans l'onglet Actions, en artefact téléchargeable.

Télécharger le fichier de workflow

Audit-code.yml audit-depot.mjs (l'analyseur)

Le workflow récupère l'analyseur automatiquement ; le second lien sert si vous voulez l'exécuter en local : node audit-depot.mjs . --rapport rapport.html

Ce que l'analyse détecte

  • Secrets et clés en dur (valeur d'exemple écartée automatiquement).
  • Constructions d'injection SQL et d'exécution de commandes.
  • Exécution dynamique de code atteignable par une entrée.
  • CORS ouvert, transport non chiffré, écriture HTML directe, hachages faibles, vérification TLS désactivée.

Ce que ce n'est pas

  • Ce n'est pas un test d'intrusion, et le code n'est jamais exécuté.
  • Ce n'est pas une garantie « zéro vulnérabilité ».
  • Un constat est une construction à risque dans le texte source, pas une faille forcément exploitable. Certains sont des faux positifs : c'est justement le travail de l'audit humain de les trier.
