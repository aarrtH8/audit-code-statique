Demander un devis

Décrivez le périmètre. Je réponds avec les limites de ce que je peux tenir et un montant ferme pour votre cas — avant tout travail.

Ne collez aucun secret ici. Ni mot de passe, ni clé d'API, ni identifiant client. Décrivez seulement le type de code et le périmètre. Pour un diagnostic immédiat sur un extrait non sensible, utilisez l'analyse locale — elle s'exécute dans votre navigateur.

Ce qui se passe ensuite, sans surprise :
  • Votre demande part vers ma boîte de réception ; rien n'est envoyé tant que vous n'avez pas cliqué sur « Envoyer » dans votre logiciel de messagerie.
  • Je réponds en indiquant ce que je peux faire, ce que je ne peux pas, et un montant ferme.
  • Si vous acceptez : facture, puis travail. Aucun paiement n'est demandé avant accord écrit sur le montant.
  • Règlement par PayPal ou virement professionnel. Aucune cryptomonnaie.

Ouvrez une demande visible sur GitHub Issues. Utile si vous voulez une trace publique.
